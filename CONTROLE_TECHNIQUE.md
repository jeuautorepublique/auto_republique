# Module Contrôle Technique

Flux :
Garage joueur → agrément → centre CT → rendez-vous → contrôle → défauts → résultat → paiement → historique véhicule → éventuelle contre-visite → autorisation de vente.

Le module est volontairement connecté au marché automobile afin de donner une vraie utilité économique aux centres tenus par les joueurs.
