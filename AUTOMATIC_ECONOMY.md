# Boucle automatique

Matières premières → stocks → industrie → véhicules → entreprises → salariés → salaires → fiscalité → trésoreries publiques → marchés publics → entreprises gagnantes → activité territoriale → banques / dettes → insolvabilité → faillite → justice / liquidation → saisies / enchères.

Cette boucle est pilotée par le serveur et le tick quotidien, afin que le monde continue à évoluer même lorsque certains joueurs sont absents.
